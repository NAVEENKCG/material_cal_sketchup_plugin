# Material Area Calculator Pro

A SketchUp plugin that calculates the total painted face area for every material in your model.

---

## Install

1. Copy `material_area_calculator_pro.rb` into your SketchUp Plugins folder:

   **Windows**
   ```
   C:\Users\YourName\AppData\Roaming\SketchUp\SketchUp 20XX\SketchUp\Plugins\
   ```
   **Mac**
   ```
   /Library/Application Support/SketchUp 20XX/SketchUp/Plugins/
   ```
   > Replace `20XX` with your SketchUp version year (e.g. 2023).

2. Restart SketchUp.

---

## Run it

**Extensions → Material Area Calculator Pro → Calculate (visible geometry only)**

- Type in the filter box to search by material name
- Click any column header to sort
- Click **Export CSV…** to save results
- Click **Rescan model** after making changes

---

## Requirements

- SketchUp 2017 or later
- Windows or macOS
